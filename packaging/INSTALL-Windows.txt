Kinu Tune - Windows (x64) インストール / Install

このビルドは GitHub Actions で自動ビルドし、Windows 上で DAW と同じ手順で読み込めることを検査しています。実際の DAW での操作はまだ確認していません。
This build is made on GitHub Actions and checked there by creating it the way a host does; it has not been used in a real DAW on Windows yet.

1. "Kinu Tune.vst3" フォルダーを次の場所にコピーします。
   Copy the "Kinu Tune.vst3" folder to:
     C:\Program Files\Common Files\VST3\

2. AI のモデルを置くフォルダーを作ります。
   エクスプローラーのアドレス欄に %APPDATA% と入力して開き、
   その中に「Keinoaza」という名前のフォルダーを、さらにその中に「Kinu Tune」という名前のフォルダーを作ります。
   Create a folder for the AI models: in File Explorer type %APPDATA% in the address bar,
   create a folder named "Keinoaza" there, and a folder named "Kinu Tune" inside it.

3. この zip の中の "models" フォルダーを、いま作った「Kinu Tune」フォルダーの中に入れます。
   Move the "models" folder from this zip into that "Kinu Tune" folder.

4. DAW を起動し直し、プラグインを再スキャンします。
   Restart your DAW and rescan plugins.

プラグインを挿すと落ちる・解析が始まらない場合は、Microsoft Visual C++ 再頒布可能パッケージ(x64、最新版)をインストールしてから、DAW を起動し直してください。
If the plug-in crashes when inserted or never starts analysing, install the latest Microsoft Visual C++ Redistributable (x64), then restart your DAW:
  https://aka.ms/vc14/vc_redist.x64.exe

ダウンロードした zip の中身がブロックされて読み込めない場合は、zip のプロパティで「許可する(ブロック解除)」にしてから展開してください。
If Windows blocks the downloaded files, open the zip's Properties, tick "Unblock", then extract again.

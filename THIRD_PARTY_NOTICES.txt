Source: https://github.com/openvpi/vocoders

The openvpi/vocoders source repository is licensed under the GNU Affero
General Public License, version 3. The complete AGPLv3 text is provided in the
LICENSE file. Corresponding source is available from the repository above.

The pretrained PC-NSF-HiFiGAN model weights are provided by the OpenVPI Team
under the Creative Commons Attribution-NonCommercial-ShareAlike 4.0
International license (https://creativecommons.org/licenses/by-nc-sa/4.0/).
Official release (other versions and future updates are available there):
https://github.com/openvpi/vocoders/releases/tag/pc-nsf-hifigan-44.1k-hop512-128bin-2025.02
Changes: the weights are not fine-tuned. They are redistributed in converted
file formats: ONNX (pc_nsf_hifigan.onnx) and a compiled Core ML model for macOS
(pc_nsf_hifigan.mlmodelc), both as included in the PitchNet 0.7.2
distributions. The Core ML model stores the weights in 16-bit floating point
(Float16), so its weight values are rounded from the original 32-bit values.
